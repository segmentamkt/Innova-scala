# Innova Escala Corp — Maqueta web

Sitio estático listo para GitHub Pages.

## Qué incluye esta versión

- Nova con rutas interactivas.
- La opción **Constituir una empresa** abre una guía real dentro de la maqueta.
- Cada ruta ofrece pasos, un recurso relacionado y acceso al formulario de orientación.
- Biblioteca de recursos gratuitos con filtros.
- Videos en estado **Próximamente**, listos para reemplazarse por YouTube/Vimeo.
- Formulario de orientación.
- Diseño responsive.

## GitHub Pages

1. Sube `index.html` y este `README.md` a tu repositorio.
2. Ve a **Settings → Pages**.
3. Selecciona **Deploy from a branch**.
4. Usa la rama `main` y `/ (root)`.

La maqueta no requiere instalación ni compilación.
